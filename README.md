# The House

> "The world itself. Seven-floored, mesophysical, self-contained. All reality manifests from within The House; no external space has been observed."

**The House** is a D&D 5e campaign setting — a cosmology where reality unfolds across seven color-coded floors (ROYGBIV), each with its own laws, inhabitants, and dangers. Floor 1 (Red) is the entrance from outside and serves as a dungeon-crawling hub where adventurers run themed dungeons, earn soul stones, and reshape the floor's economy.
